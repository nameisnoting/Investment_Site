### 시스템 판정
- **고용 상태**: `unemployed` → **보수 모드 자동 발동**

- **자산 tier**: `small`
- **예금 유지 60%**: 3,500만 × 60% = **2,100만 예금 그대로**
- **투자 가능**: 700만원 (코어 ETF + 위성 모두 합쳐 이만큼만)

## 🎯 시나리오 비교에서 보이는 시스템 가치

### 1. 같은 시장이라도 사용자에 따라 추천이 극단적으로 달라짐
- 시나리오 1: 코어 73% / 위성 12% (보수)
- 시나리오 3: 코어 21% / 위성 64% (공격)
- **3배 이상의 차이** — 일반 로보어드바이저로는 불가능

### 2. 위험 슬라이더가 단순 가중치가 아니라 자산 행동을 바꿈
- 시나리오 1의 예금 보존 60% vs 시나리오 3의 10%
- "투자에 묶지 마라"는 사용자 의지가 결과에 직접 반영

### 3. 동일 종목 추천도 비중이 다름
- 셋 다 MSFT 추천 (시장 1등 점수)
- 하지만 시나리오 1은 2.3%, 시나리오 3은 14.6%
- 같은 종목도 자산 규모에 맞는 의미 있는 비중

### 4. 백수 모드 / 재직 모드 자동 분기
- 시나리오 1만 비상자금 6개월치 (소득 단절 대비)
- 시나리오 2,3은 3개월치 (재직 기본)
- 같은 자산이라도 소득 상태로 추천이 갈림

핵심 관찰:
- **같은 사용자라도 모드가 결과를 완전히 다른 포트폴리오로** — 같은 시장이라도 4가지 다른 시선
- **장기 = 우량주 위주** (MSFT/JPM/V) / **모멘텀 = 신흥주 위주** (IONQ/OKTA/ZS)
- **모멘텀은 현금 30% 강제** — 단기 변동성 노출 제한
- **혼합은 진짜 섞임** — 장기의 MSFT/JPM + 폭등의 PLTR/AFRM + 모멘텀의 IONQ가 한 화면에

## 모드별 상세

### 1. 장기투자
- **코어 ETF 5종 모두 포함** (BND 채권 19%로 안전성 ↑)
- 한국 ETF (EWY) 코어에 + 한국 개별주(로컬만) 8.5%
- 위성은 빅테크 + 금융주 위주의 우량주
- **사용자 의도**: 5~10년 보유, 변동성 최소화, 시장 평균 + 알파 약간

### 2. 폭등시그널 🚀
- **레버리지 3x ETF 12.7%** — TQQQ/SOXL/UPRO 자동 비중 분배
- 코어는 BND/SCHD 제거 → VOO/QQQ만 (성장 강조)
- 위성은 그로스 종목 (IONQ 매출 +334%, PLTR, AFRM)
- **사용자 의도**: 중단기 알파 추구, 변동성 감수, 다음 폭등주 노림

### 3. 모멘텀 추종 ⚡
- **현금 30% 강제** — 단기 트레이딩의 변동성 회피
- 코어는 QQQ만 (단순)
- 위성은 **모두 MOMENTUM_RIDE 액션** (IONQ +45%, OKTA, ZS +36%, S)
- 손절선 -7% 자동 명시
- **사용자 의도**: 강한 추세 종목 단기 올라타기, 매수 후 -7% 손절

### 4. 혼합 (가중치 50/30/20)
- **3개 모드 결과를 가중 합성** — 같은 종목이 여러 모드에 나오면 비중 합산
- IONQ: 폭등(8.6%) + 모멘텀(14.6%) → 합쳐서 6.5% (모드 가중치 적용)
- 한 화면에 11종목 — 다양한 의도 혼재
- 레버리지 비중도 surge에서 30%만큼 → 3.8%로 축소
- **사용자 의도**: "한 가지에 올인 못 하겠어, 적절히 분산"

## PM 의도 검증

- ✅ 4모드가 명확히 차별화 — 같은 입력으로 4가지 다른 결과
- ✅ 모드 내에서도 risk_level 슬라이더가 추가 조정 (폭등에서 레버리지 0~30%)
- ✅ 혼합 모드가 진짜 의미 있는 합성 (단순 평균이 아니라 종목 중복 처리)
- ✅ 모멘텀의 현금 30% 강제로 "단기 트레이딩의 절제" 자동 반영

## 데모 시연 흐름 (포트폴리오 발표 시)

1. 시나리오 2 입력값 채우기
2. 전략 = **장기투자** → 결과 캡처
3. 전략 = **폭등시그널** 로 변경 (입력값 그대로) → 결과 캡처 (TQQQ/IONQ 등장)
4. 전략 = **모멘텀** → 결과 캡처 (현금 30%, 전부 MOMENTUM_RIDE)
5. 전략 = **혼합** → 결과 캡처 (셋이 섞임)
6. 백테스팅 1년 → 차트로 과거 성과 검증

→ 채용 담당자가 1분 안에 "이 도구는 진짜 다양한 사용자 의도를 표현한다"를 인지.
